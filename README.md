# Fitbit Activity Dashboard

## Project Overview
This project analyzes Fitbit user activity data using Tableau to identify trends in daily activity, calories burned, sleep, and fitness performance.

## Tools Used
- Tableau
- Excel
- Fitbit Dataset

## Dashboard Features
- Daily Steps Analysis
- Calories Burned
- Active Minutes
- Sleep Analysis
- Interactive Filters

## Key Insights
- Daily activity trends
- Relationship between steps and calories
- User fitness patterns
