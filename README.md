# Fitbit Health & Activity Dashboard

An interactive **Tableau dashboard** built to analyze Fitbit fitness tracker data and uncover insights into users' daily activity, calories burned, heart rate, sleep patterns, and overall fitness performance.

---

## 📌 Project Overview

The Fitbit Health & Activity Dashboard provides an interactive visualization of Fitbit user data, helping users understand activity levels, health metrics, and fitness trends through dynamic charts and filters.

This project demonstrates data visualization, dashboard design, and business intelligence skills using Tableau.

---

## 🎯 Objectives

- Analyze daily physical activity patterns.
- Monitor calories burned and step count.
- Evaluate heart rate trends.
- Study sleep duration and quality.
- Build an interactive dashboard for data exploration.
